# 隐私与数据

LYPH 是一个自托管项目。**数据控制者是你的部署者**，不是本项目作者。

## 收集什么

| 数据 | 用途 | 默认保留 |
|---|---|---|
| 访客 IP | 访问统计、防滥用 | 30 天 |
| 访客 cookie | 匿名会话标识 | 会话/哈希 |
| 聊天正文 | 回答、历史、缓存 | 30 天后置空（运行中除外） |
| 截图/速记 | 日报、个人记录 | 截图 7 天 |
| 审计 / MCP 调用 | 安全与排障 | 180 天 |
| 登录失败 IP | 限流 | HMAC 摘要，15 分钟窗口 |
| 模型密钥 | 调用模型 | 加密存储，直到删除 |

## 不收集什么

- 不要求访客注册
- 不记录明文密码
- 不记录模型原始回复（只保存经过处理的回答/视图）
- 不把 owner/预览/测试事件计入访客统计

## 数据流向

```text
浏览器 → 你的 Nginx/Next.js/FastAPI → 你的 SQLite/MinIO
                                      → 你配置的模型 API
```

- 模型 API 由部署者选择；请阅读其隐私条款。
- 如果启用 AI Horde 等公共匿名端点，问题会发送到该服务。
- 如果启用企业快照，只读取部署者提供的只读 SQLite。

## 部署者义务

- 在站点隐私政策中说明采集范围、目的、保留期
- 提供删除/导出联系方式
- 遵守当地法律（PIPL/GDPR 等）
- 不要公开真实访客 IP、聊天记录、截图
- 不要提交 `data/`、`runtime/`、`backups/`、`public-apps/`

## 删除数据

- 后台删除内容/设备/聊天
- 清理任务：

```bash
uv run --project api --env-file .env lyph cleanup
```

- 彻底删除：停止服务，删除 `data/`、MinIO bucket、`backups/`
- 访客请求删除：按聊天/设备记录定位后删除；无法定位匿名 cookie 时说明限制

## 保留期调整

保留期目前在 `api/lyph/operations.py` / `devices.py` 中定义。公开版本保留默认值；如果你需要合规，建议把它们改成配置项，并在隐私政策中同步。

## 安全事件

如果怀疑数据泄露：

1. 停止服务
2. 轮换模型 Key、MinIO Key、`LYPH_SECRET_KEY`
3. 让所有 session 失效（恢复备份或清 session 表）
4. 检查审计日志
5. 通知受影响用户（如适用）
